QUESTIONS

Short answers.

What currency do people receive?

Payouts settle in stablecoins by default. Each signer can attach an off-ramp so the share arrives as local currency in a bank account the same day.

Can a split be changed later?

Yes, but only by all current signers together. Every version is kept, so an old statement can always be traced to the sheet that produced it.

What if someone loses their wallet?

A share is a seat, not a key. Signers can rotate the receiving address by consensus without touching the percentages.

Do listeners need a wallet?

No. Rondo sits behind the platforms your audience already uses — the protocol only changes what happens after the money arrives.

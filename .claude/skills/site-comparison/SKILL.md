# Процесс 3 — сравнительное видео (переиспользует ИИ-клон)

Полный шаблон и правила — в **`generated-sites/comparison-video/README.md`** (прочитай его).
Скрипт монтажа — `generated-sites/comparison-video/make_comparison.js` (делает ВСЁ: запись
обоих скроллов + рендер короны/подписей + монтаж). Ниже — рабочий чек-лист.

## Вход
- Аргумент `$ARGUMENTS` = `<slug>` готового сайта в `generated-sites/<slug>/index.html`.
  Если не указан — уточни, для какого сайта.

## Шаги

1. **Проверь вход.** Убедись, что `generated-sites/<slug>/index.html` существует, и возьми
   `cs` (dark/light) из `projects.json`. **Содержимое `index.html` не открывай** — для монтажа
   оно не нужно, а для клона запрещено (см. шаг 2).

2. **ИИ-клон: переиспользовать существующий, не плодить новый.**
   Проверь, есть ли `generated-sites/<slug>/comparison/ai-version.html`.
   - **Файл ЕСТЬ** (обычно уже создан через /site-slop) → используй его как есть, НИЧЕГО не
     переписывай. Переходи к шагу 3.
   - **Файла НЕТ** → создай его строго по скиллу **`site-slop`** (прочитай
     `.claude/skills/site-slop/SKILL.md` целиком и пройди все 5 шагов): опись секций по
     скриншотам от `shot.js`, деградация каждой секции в дефолтный примитив, палитра на глаз,
     признаки слопа. **В код `index.html` не заглядывать** — клон собирается по кадрам.
     Затем шаг 3.

3. **Смонтируй видео** одной командой:
   ```bash
   node generated-sites/comparison-video/make_comparison.js \
     --design generated-sites/<slug>/index.html \
     --ai     generated-sites/<slug>/comparison/ai-version.html \
     --out    generated-sites/<slug>/comparison
   ```
   Флаги при желании: `--label-top`, `--label-bottom`, `--crown bottom|top|none`, `--avg 220`,
   `--hold 2.5` (пауза на первом экране), `--sync on|off`.
   Скрипт сам пишет оба скролла (1920×1080, медленный старт), рендерит корону/подписи, собирает
   финал (2016×2730, 60fps). Занимает 3–6 мин (зависит от высоты сайтов).
   Частота меняется флагом `--fps`; на длительность она не влияет (кадры = секунды × fps),
   так что 60 fps — это просто вдвое больше снятых кадров на ту же длину.

   **Где окажется файл:** сам ролик — в общей папке `generated-sites/_videos/<дата>/<slug>.mp4`
   (дата = сегодняшний день генерации, чтобы пачки роликов не сваливались одной кучей), а в папке
   сайта скрипт создаёт симлинк `<slug>/comparison/comparison-final.mp4` → на него. По старому
   пути (через симлинк) всё продолжает открываться. Скролл-видео остаются в папке сайта.
   Специально ничего перекладывать не надо — дату скрипт проставляет сам.

4. **Пересобери галерею** — `python3 build_generated.py`: статус «ИИ-слоп / Видео» на карточке
   читается с диска, без пересборки чипы останутся серыми.

5. **Отдай результат** через SendUserFile: `generated-sites/<slug>/comparison/comparison-final.mp4`
   (путь через симлинк — не завязан на дату, в отличие от общей папки `_videos/<дата>/`).

## Грабли (уже учтено в скрипте, не сломать)
- Запись через `waitUntil:'domcontentloaded'` — иначе сайты с Google Fonts без сети виснут.
- Финал жёстко ограничен `-frames:v N` — иначе `-loop 1` картинки кодируются бесконечно.
- Высоты сайтов НЕ подгонять: разная длина ок — при `--sync on` (по умолчанию) короткий
  сайт скроллится медленнее и финиширует вместе с длинным.
- Без сети Google-шрифты дизайн-сайта падают в системный фолбэк (обычно приемлемо).
- `comparison-final.mp4` в папке сайта — **симлинк**, а не файл. Не заменять его копией и не
  удалять ролик из `_videos/<дата>/` руками: чистит всё `delete_site.py`.

## Не делать
- Не запускать перепроверочные извлечения кадров без явной просьбы (пользователь смотрит сам).
- Не коммитить в git.

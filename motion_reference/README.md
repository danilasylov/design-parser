# Личная база оригинальных примеров веб-анимации

В каталоге 142 визуальных паттерна, 23 типа и 1944 исходных варианта и реализации. Направления и способы одного эффекта объединены внутри паттерна; в частности, 662 варианта Animista представлены 21 паттерном. Снимок публичных каталогов: 14 октября 2026 года.

## В составе Design Parser

Основной запуск: `python3 scripts/project.py start` из корня Design Parser
(Windows: `start-windows.cmd` или `py -3 scripts/project.py start`). Каталог доступен
по `/motion_reference/` на том же сервере. Дальнейшие разделы описывают исходный
полный локальный архив. В публичном Git-комплекте видеопревью, архивы Codrops
и компоненты React Bits не поставляются: выбранное скачивается из корня командой
`python3 scripts/fetch_assets.py --motion <example-id>` (Windows: `py -3`).
Полный исходный архив остаётся локально; публичный клон не является его точной копией.
Инструкции по ZIP и `.command` ниже нужны только для отдельного старого архива.
Новые проверки и описание поставки: `../README.md`, `../THIRD-PARTY-NOTICES.md`.

## Как открыть

1. Скачай основной архив и оба архива `codrops_previews_part1.zip`, `codrops_previews_part2.zip` в одну папку.
2. Распакуй основной архив. Папка справочника называется `motion_reference`. Два видеоархива можно оставить рядом с этой папкой.
3. Внутри `motion_reference` запусти `python3 serve.py`. На Mac также есть `start_mac.command`. Запускатель сам извлечёт видеопревью из соседних архивов и откроет справочник в браузере.

Python 3 работает со стандартной библиотекой: установка пакетов, npm и API-ключи для просмотра не нужны. Для остановки сервера нажми Ctrl+C. `index.html` также открывается напрямую для сохранённых видео и CSS; интерактивные React-демо используют локальный запускатель.

## Поиск и применение

В боковой панели выбери тип, затем паттерн и источник. Внутри паттерна выбери способ реализации и направление. Фильтр запуска помогает найти hover, click, scroll, drag или автоматическую анимацию. Поиск понимает оригинальные названия, русские названия классов и теги. У каждого примера подписан способ взаимодействия: автоматически, курсор, клик или повтор CSS-эффекта при наведении. Название паттерна открывает подробности, варианты, код и ссылки автора. Нативные компоненты не имеют внутренней полосы прокрутки; видеореференсы для ещё не подключённых исходников обозначены отдельно.

Это справочник оригинальных примеров для собственной веб-разработки. Классификация выведена из опубликованных названий, описаний, тегов и кода, с отдельными правилами для компонентов. Она не является отраслевым стандартом. Не все сценарии взаимодействий каждого проекта вручную проверены.

Для использования бери исходный компонент/CSS или код проекта, изучай параметры и адаптируй содержимое под свой сайт. Условия автора сохранены в `LICENSE` и внутри снимков кода. Записанное видео показывает оригинальное демо; интерактивность берётся из исходника.

Снимки Codrops сохраняют оригинальные кодовые и текстовые файлы, структуру путей, сведения о версии и лицензии. Крупные фото, видео, модели и другие бинарные ресурсы исходных проектов доступны в полных репозиториях по ссылкам в карточках. Само видеопревью эффекта включено в комплект. Старые демо с сервером, картами, камерой или внешними API могут требовать исходное окружение.

Четыре исходные ссылки на репозитории возвращают 404: `AhmedKabbej/gobzzzmusicplayer2024`, `mattverse/what-i-love`, `rock-biter/fire-trails`, `sergejcodes/codrops-minze-demo`. Их записи и доступные примеры сохранены; отсутствие архива кода отмечено. Пять старых MP4-ссылок в документации Magic UI также возвращают 404; соответствующие компоненты доступны в локальном живом просмотре.

```sql
SELECT provider, COUNT(*) FROM animation_examples GROUP BY provider;
SELECT type_id, class_id, COUNT(*) FROM animation_examples GROUP BY type_id, class_id;
SELECT name, demo_url, details_json FROM animation_examples WHERE provider = 'codrops' AND type_id = 'cursor';
SELECT e.name, f.role, f.path FROM animation_examples e JOIN example_files f ON f.example_id = e.id WHERE e.id = 'react-bits.blob-cursor';
```

## Анимации, встроенные в страницу

Animista (662 примера) и Magic UI (79 примеров) теперь монтируются прямо в DOM каталога, без iframe, кнопок запуска и паузы. Анимации запускаются при появлении на экране. Наведение или нажатие повторяет CSS-эффект Animista; React-компоненты Magic UI сохраняют исходные реакции на мышь, клики и ввод. Стили изолированы с помощью Shadow DOM. За пределами видимой области компоненты размонтируются для экономии ресурсов, а при возвращении появляются заново. Для Magic UI запускай каталог через `Открыть каталог.command`. React Bits и Codrops пока сохраняют прежний способ предпросмотра.

Исходники встроенной сборки — `viewer_source/inline.jsx`, `inline.css`, `vite.inline.config.js`. Пересборка: `cd viewer_source`, `npm ci`, `npm exec vite build -- --config vite.inline.config.js`. Папка `official` ссылается на сохранённые оригиналы Magic UI.

## Группировка по паттернам

`pattern-catalog.js` задаёт смысловые группы, объединяет направления и способы появления/исчезновения, а также реализации разных библиотек. `catalog-app.js` показывает одну карточку на паттерн и переключает его варианты. Поиск, фильтры, счётчики и пагинация работают с паттернами. Сохранены все исходные идентификаторы, файлы, лицензии и ссылки.

Актуальная выгрузка: `pattern_catalog.json` и `animation_patterns.csv`. Исходная база `motion_catalog.json` / SQLite хранит первоначальные записи и классификацию для сохранения происхождения. Пересоздание выгрузки: `node scripts/export-patterns.mjs`. Проверка сохранности и группировки: `node scripts/check-patterns.mjs`.

В `viewer_source/interactive-grid.jsx` к оригинальному Animated Grid Pattern добавлены подсветка ячейки под курсором и импульс по нажатию. В каталоге он обозначен как адаптация; оригинал в `originals/` сохранён. Автоматические эффекты не обозначаются интерактивными только из-за наличия слова `pointer` или `drag` в исходном коде. Полосы прокрутки контейнера удалены, размеры исходных демонстраций ограничены доступной областью. CSS property-регистрации Tailwind подключены к документу отдельно для корректного отображения градиентов и трансформаций внутри Shadow DOM.

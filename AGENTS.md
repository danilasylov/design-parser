# Работа с Design Parser

Общайся с пользователем на русском. Начни с `README.md`; Windows: `docs/WINDOWS.md`.
Архитектура и исходный процесс — в `CLAUDE.md` и `.claude/skills/site-from-ref/SKILL.md`.

## Сайт с подбором референсов и анимациями

Для такого запроса прочитай и выполни `.agents/skills/site-from-ref-motion/SKILL.md`.
В Claude Code доступен `/site-from-ref-motion`. Поиск сканирует всю базу, подробный
визуальный разбор делается для лучших кандидатов. FFmpeg разбирает видео; полную
страницу записывает Playwright. Не называй хиро-превью просмотром всей страницы.

## Анимации при генерации сайта

Подбирай эффекты напрямую из локального `motion_reference/` под концепцию сайта.
Изучай исходник и демо, адаптируй к стеку сайта и сохраняй лицензии. Направления,
скорость, easing и реализации одного паттерна — варианты внутри одной карточки.
Для выбора используй `pattern_catalog.json`, а не плоский список вариантов.
Проверяй движение и взаимодействия в браузере, начальный и динамический
`prefers-reduced-motion`, паузу циклов и читаемость без JS.

## Переносимость и запуск

Для просмотра достаточно Python 3.9+ и обычного браузера пользователя.
Для вспомогательных скриптов нужны Node.js 22+ и `npm ci`.
Не устанавливай Chromium автоматически для тестов: используй доступный браузер
агента. Playwright/Chromium — дополнительная автоматизация по явному запросу.
Windows: `py -3`; macOS/Linux: `python3`. Команды исполняются из корня проекта.
Не добавляй абсолютные пути автора, macOS-бинарники, node_modules, секреты или
React Bits-компоненты в Git. Медиа загружай по выбранным ID через
`scripts/fetch_assets.py`; код с неизвестной лицензией используй только как референс.
После работы сервер должен быть доступен на http://localhost:8080/generated-sites/.
Запуск: `python3 scripts/project.py start --no-open` (Windows: `py -3`).
Новый процесс не запускает `/site-slop` и сравнение автоматически.

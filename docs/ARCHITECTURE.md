# Карта проекта для агента

Все пути относительны корню. `AGENTS.md` — точка входа, `CLAUDE.md` — подробные
соглашения старой галереи. Новый процесс описан в
`.agents/skills/site-from-ref-motion/SKILL.md`; `.claude/skills/site-from-ref-motion`
содержит адаптер, чтобы не поддерживать две расходящиеся копии.

## Данные и сборка

`all_styles.json` + `classification.json` → `build_gallery.py` → `site-copy/index.html`.
`sections.json` → `build_sections.py` → `sections/index.html`.
`generated-sites/projects.json` → `build_generated.py` → `generated-sites/index.html`.
Оценки хранятся отдельно в `ratings.json` и записываются через `serve.py`.

`motion_reference/motion_catalog.json`/SQLite сохраняют происхождение и все 1944
варианта. `catalog_data.js` — данные визуального каталога. `pattern-catalog.js`
группирует реализации по механизму; `scripts/export-patterns.mjs` создаёт
`pattern_catalog.json` и CSV. Каталог и новый поиск используют эту группировку.
`scripts/check-patterns.mjs` проверяет сохранность всех ID, уникальность групп и
объединение направлений. Группировка семантическая и может уточняться вручную.

## Новый процесс

1. `select_references.py sites`: сканирует весь корпус и выдаёт небольшой список
   с оценкой и совпавшими терминами. Синонимы RU/EN явные; нет скрытого API/LLM.
2. `fetch_assets.py`: загружает только выбранные материалы, атомарно, с повторами,
   лимитом потоков и проверкой хешей там, где загружается тот же оригинал.
3. `storyboard.cjs`: FFmpeg декодирует всю длительность и выбирает 12 кадров,
   собирает контактный лист, сохраняет время/параметры и кэш.
4. `capture_site.cjs`: Playwright записывает браузер, последовательно прокручивает
   документ с перекрытием экранов, ждёт стабилизации внизу и проверяет покрытие.
   Затем тот же FFmpeg строит обзор записи. Нет скрытого обхода сайта по всем URL:
   «весь сайт» здесь означает всю основную страницу, скрытые состояния проверяет агент.
5. `select_references.py motion`: один результат на паттерн с выбранной реализацией.
   Разные направления не расходуют места в поисковой выдаче.
6. Агент читает исходники/лицензии, смотрит демо, адаптирует код и сохраняет
   `index.html`, `motion-plan.json`, `THIRD-PARTY-NOTICES.txt` в папку сайта.
7. `qa_motion.cjs`: проверяет изменения CSS-свойств во времени после триггера,
   EN/RU, overflow, паузу, reduced motion и контент без JS. Canvas требует
   дополнительной проверки кадров. Скриншоты нужно открыть и оценить глазами.
8. Регистрация в `projects.json`, сборка галереи и работающий локальный сервер.

## Публичный комплект и локальная база

Git исключает скачанные Refero-медиа, исходники React Bits, Codrops ZIP, записи,
машинные настройки и node_modules. Исходные данные не удаляются с диска.
Репозиторий не публикует частный медиаархив через Releases или Git LFS.
Доступные MIT Magic UI и FreeBSD Animista сохраняют лицензии в комплекте.

Загрузчик React Bits получает файлы у автора по сохранённому commit; оригинальное
WebM — с сайта автора. Сгенерированные ранее MP4/JPG не выдаются за оригинал.
Codrops загружается в `motion_reference/upstream/<owner>__<repo>@<sha>.zip`:
полный архив отличается от старого отфильтрованного снимка, его хеш не подменяется.
Снимки без ясных условий использования нельзя считать разрешёнными автоматически.

## Разработка

Python — stdlib, минимум 3.9. Node — 22+. `package-lock.json` в Git.
`project.py` выбирает `npm.cmd` на Windows; пути к FFmpeg предоставляет npm-пакет,
локальные файлы открываются через `pathToFileURL`. Кодировки файлов заданы UTF-8.
Основной процесс не требует симлинков или команд конкретной оболочки.

Просмотр анимаций использует готовые сборки. Для изменения React-демо отдельно:
`cd motion_reference/viewer_source`, `npm ci`, затем
`npm exec vite build -- --config vite.inline.config.js`. Оригинальные Magic UI
доступны в `../originals/magic-ui`, без обязательного симлинка `official`.

Проверки: `npm test`, `npm run patterns`, `python3 scripts/project.py doctor`.
CI выполняет сборку и проверки на Windows/Linux. Тесты не скачивают весь архив,
не генерируют новые сайты с LLM и не обещают доступность внешних источников.

# Design Parser

Локальная библиотека дизайн-референсов и анимаций для создания сайтов с ИИ-агентом.
Всё находится в одной папке: **1288 сайтов**, их категории и анатомия страниц,
**142 паттерна анимации / 1944 варианта**, галерея готовых работ и скилл генерации.

Новый процесс `site-from-ref-motion` подбирает референсы под бриф, разбирает видео
через FFmpeg, при необходимости записывает всю страницу в браузере и добавляет
подходящие анимации. Он сохраняет дизайн-токены исходного Site from Ref и проверяет
результат в EN/RU, с уменьшенным движением и без JavaScript.

## Быстрый запуск на Windows

1. Установи [Python](https://www.python.org/downloads/windows/) с Python Launcher
   и [Node.js](https://nodejs.org/en/download) версии 22 или новее. После установки
   открой новое окно терминала.
2. Нажми **Code → Download ZIP** на GitHub и распакуй проект, например в
   `C:\Projects\design-parser`. Git необязателен.
3. Дважды нажми **`setup-windows.cmd`**. Он установит зависимости,
   соберёт галереи и скачает сохранённые видео/постеры из GitHub Releases
   (около **1,56 ГБ**, только при первой установке). Нужен интернет.
4. Дважды нажми **`start-windows.cmd`**. Откроется [Design Parser](http://localhost:8080/).
   Оставь окно сервера открытым. Остановка — Ctrl+C.

Подробности, команды PowerShell и решение проблем: **[Windows-гайд](docs/WINDOWS.md)**.

macOS/Linux: Python 3.9+ и Node.js 22+, затем из корня проекта:

```sh
python3 scripts/project.py setup
python3 scripts/project.py start
```

FFmpeg устанавливается пакетом `ffmpeg-static` под текущую ОС. Копировать macOS-
бинарник на Windows не требуется. Git LFS, Docker, API-ключи и платная БД не нужны.
Для просмотра библиотеки достаточно Python: `py -3 scripts/project.py start`
на Windows или `python3 scripts/project.py start` на macOS/Linux. Открой адрес
в своём обычном браузере. Chromium автоматически не устанавливается; он нужен
только для необязательных скриптов записи/тестирования Playwright. Если такие
скрипты действительно понадобятся: `python3 scripts/project.py setup --with-browser`.

## Как попросить агента сделать сайт

### Первый готовый пример — Prism BI

Prism BI уже включён в проект и показан первым в галерее. После запуска открой
[демонстрационный сайт](http://localhost:8080/generated-sites/prism-bi/).
Это интерактивный BI-блокнот с EN/RU, анимациями, выбором вопросов и CSV-экспортом.
Ничего генерировать или скачивать из каталога для этого примера не требуется.

Можно скачать только [Prism BI в ZIP](https://github.com/danilasylov/design-parser/raw/refs/heads/main/demo/prism-bi.zip),
распаковать и открыть `prism-bi/index.html` в обычном браузере Windows или macOS.
В архиве находятся HTML, дизайн-токены, описание референса и лицензии.
CSS/JS встроены в HTML; Google Fonts загружаются из интернета с системным fallback.
Файлы исходного примера: [`generated-sites/prism-bi/`](generated-sites/prism-bi/).

### Новый сайт

Второй готовый пример — **VESPER®**, студия кинетических скульптур и световых
инсталляций с WebGL-сценами, интерактивными объектами и EN/RU. Он также включён
в проект и закреплён сразу после Prism BI в галерее.
[Открыть локально](http://localhost:8080/generated-sites/vesper/index.html) ·
[Скачать VESPER ZIP](https://github.com/danilasylov/design-parser/raw/refs/heads/main/demo/vesper.zip).
Распакуй и открой `vesper/index.html`; сборка и установка зависимостей для просмотра
не требуются. Для 3D-сцен нужен обычный браузер с поддержкой WebGL.

### Создание своего сайта

Открой **всю папку проекта** в своём агенте и отправь:

> Прочитай AGENTS.md и .agents/skills/site-from-ref-motion/SKILL.md.
> Сделай сайт для независимого музыкального фестиваля. Сам подбери подходящие
> референсы из базы, посмотри их видео и всю страницу, добавь много уместных
> анимаций из каталога. Одинаковые паттерны с разными направлениями не считай
> разными эффектами. Проверь EN/RU, reduced motion и читаемость без JS.

В Claude Code: `/site-from-ref-motion <тема и пожелания>`.
Основной текст скилла хранится в `.agents/skills/`, Claude-адаптер — в `.claude/skills/`.
Другому агенту достаточно прочитать тот же файл; специальные MCP-серверы не нужны.
Сам проект не обращается к LLM API: сайт пишет агент, в котором открыта папка.

Результат: `generated-sites/<slug>/index.html`, `motion-plan.json`, лицензии и
карточка в галерее. По умолчанию это самостоятельный десктопный HTML-сайт,
EN — основной язык, RU переключается в шапке. Иной стек/размер можно задать в брифе.

## Что входит в публичный репозиторий

| Часть | Назначение |
|---|---|
| `all_styles.json`, `classification.json` | Поиск по всем 1288 референсам |
| `sections.json`, `sections/` | Сохранённая анатомия страниц |
| `site-copy/` | Галерея сайтов и ссылки на авторов |
| `motion_reference/` | База JSON/SQLite, каталог паттернов, разрешённый код и демо |
| `generated-sites/` | Примеры созданных сайтов и индекс проектов |
| `.agents/skills/site-from-ref-motion/` | Новый процесс генерации |
| `.claude/skills/` | Исходные процессы и Claude-адаптер |
| `scripts/` | Поиск, загрузка материалов, запись, FFmpeg и QA |
| `docs/ARCHITECTURE.md` | Карта проекта и команды для агента |

Полный сохранённый медиапакет референсов опубликован в
[GitHub Releases этого проекта](https://github.com/danilasylov/design-parser/releases/tag/reference-media-v1):
**1031 видео и 1288 постеров**, четыре ZIP-части. Установщик восстанавливает
их в `site-copy/media/`; видео проигрываются прямо в карточках, без перехода
на оригинальные сайты. Файлы сохранены без перекодирования.
Обычный Code → Download ZIP содержит код и манифест; большие медиа скачиваются
установщиком из Releases. Так Git-история остаётся небольшой, а полный архив
превью доступен в том же GitHub-проекте независимо от исходных CDN.

Видеопревью анимаций, архивы Codrops, компоненты React Bits,
записи проверок, локальные права агента и зависимости отдельно не публикуются.
Основные CSS-демо Animista и встроенные Magic UI включены;
отдельные демо с фото/видео и внешними API могут требовать дополнительных ресурсов.
Локальный исходный комплект содержит больше материалов, чем публичный Git-клон.

## Все движущиеся превью «Референсов»

На Windows достаточно дважды нажать **`download-reference-media.cmd`**.
Нужен только Python; Chromium и Node.js не нужны. На macOS/Linux:

```sh
python3 scripts/install_reference_media.py
```

Обычный `scripts/project.py setup` также устанавливает этот медиапакет.
Для установки только инструментов: `python3 scripts/project.py setup --without-reference-media`.
После установки открой вкладку «Референсы»: при включённом «Авто-видео»
видимые карточки проигрываются автоматически, клик или тап ставит отдельное
видео на паузу и запускает его снова. 257 карточек,
у которых исходного видео не было, сохраняют постеры.

Загрузчик проверяет SHA-256 архивов и каждого файла. Прерванная загрузка
продолжается; уже установленные исправные файлы пропускаются. Временные архивы
удаляются после распаковки, чтобы не занимать лишнее место. Понадобится примерно
2 ГБ свободного диска. Проверить установленный комплект без сети:
`python3 scripts/install_reference_media.py --verify-only`.

Можно скачать четыре части вручную со страницы Releases и распаковать поверх
корня проекта. Для проверки и распаковки установщиком используй
`python3 scripts/install_reference_media.py --archive-dir <папка-с-четырьмя-ZIP>`.

## Загрузка отдельных материалов из исходных источников

Windows: замени `python3` в примерах на `py -3`.

```sh
python3 scripts/select_references.py sites "финтех dark editorial" --limit 8
python3 scripts/fetch_assets.py --sites 1a519123-071a-449f-b5df-0def73ed7f35
python3 scripts/select_references.py motion "появление текст scroll hover"
python3 scripts/fetch_assets.py --motion react-bits.animated-content
```

В `--sites` и `--motion` можно передать несколько ID или `all`. Полная загрузка
превью велика; обычно достаточно выбранных референсов. Локальные непустые файлы
повторно не скачиваются; для индексированных оригиналов проверяется SHA-256.
Результат загрузки: `.cache/downloads.json`; ошибка источника даёт ненулевой код
выхода. Источник может измениться или перестать отвечать: это не скрывается.
Если медиа автора изменилось, загрузчик по умолчанию отклонит несовпадение хеша.
После проверки источника можно повторить с `--allow-updated`: это разрешает
новые медиа, записывает фактический и прежний SHA-256 и не меняет хеш исходного каталога.
На исходный код этот флаг не распространяется.
Загрузчик не воспроизводит побайтно весь частный архив: свежие архивы Codrops
хранятся отдельно, а производные MP4/JPG React Bits заменены оригинальным WebM.

## Без повторяющихся карточек анимаций

Слева, справа, сверху, снизу, easing и скорость — варианты одного паттерна.
Разные библиотеки с тем же механизмом также входят в одну карточку.
В каталоге сначала выбирается паттерн, внутри него — реализация и направление.
Выбор скилла основан на `pattern_catalog.json`; плоская база сохраняется для
источников и точных параметров. Удалять исходный вариант для этого не требуется.

Пересобрать и проверить группировку: `npm run patterns`.
Проверки гарантируют сохранность ID и объединение направлений; смысловую
классификацию можно уточнять в `motion_reference/pattern-catalog.js`.

## Проверки и ограничения

```sh
python3 scripts/project.py doctor
npm test
node scripts/storyboard.cjs <video> .cache/storyboard
node scripts/capture_site.cjs https://example.com .cache/capture
node scripts/qa_motion.cjs <site.html> <motion-plan.json> .cache/qa
```

Обзор видео — 12 кадров по всей длительности с кэшем; сложный фрагмент можно
разобрать отдельно. Полный сайт записывает Playwright с прокруткой до футера.
Это не проверка всех скрытых меню/hover-состояний: их агент смотрит дополнительно.
Бесконечный скролл и недоступные страницы отмечаются как ограничение.
Проверки сборки, поиска, FFmpeg и загрузчика запускаются в GitHub Actions на Windows
и Linux; браузерные тесты включаются отдельно при ручном запуске workflow.

Локальный сервер сохраняет оценки в `generated-sites/ratings.json`; GitHub Pages
для этого не подходит. Ссылка GitHub позволяет другу скачать проект и дать его
своему агенту. Работающая библиотека открывается у него локально после запуска.

Материалы принадлежат исходным авторам. Условия и особенности повторного использования:
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Название проекта не даёт общую
лицензию на все сайты, шрифты, изображения и сторонний код.

# Refero Styles — локальная видео-галерея

Офлайн-копия галереи сайтов с **styles.refero.design**: все превью-видео скачаны
локально, каждая карточка ведёт на оригинальный сайт.

## Как открыть

После скачивания кода с GitHub сначала установи медиапакет проекта:
Windows — `download-reference-media.cmd` из корня; macOS/Linux —
`python3 scripts/install_reference_media.py`. Все 1031 видео и 1288 постеров
хранятся в GitHub Releases: загрузчик восстанавливает их с проверкой SHA-256.
Затем запусти проект и открой `http://localhost:8080/site-copy/`.
Все движущиеся превью доступны прямо в карточках, не требуется посещать оригиналы.

**Просто дважды кликни по `index.html`** — откроется в браузере, видео и
картинки подгрузятся с диска.

Если в твоём браузере видео по `file://` не проигрывается (бывает в некоторых
версиях Chrome), запусти локальный сервер:

```bash
cd site-copy
python3 -m http.server 8080
# затем открой http://localhost:8080
```

## Что внутри

- `index.html` — сама галерея (поиск, фильтры «Все / С видео / Без видео»,
  дропдауны «Категория» и «Стиль»).
- `media/videos/<id>.mp4` — превью-видео (1200×750).
- `media/thumbs/<id>.jpg` — постеры/скриншоты (показываются до запуска видео).

## Как пользоваться

- **Наведи курсор** на карточку — превью-видео начнёт играть. Убери курсор — пауза.
  На телефоне — **тап** по карточке запускает/останавливает видео.
- **Категория** (финтех, e-commerce, портфолио…) и **стиль** (дарк, минимализм,
  брутализм…) — дропдауны в шапке; работают вместе с поиском и остальными
  фильтрами. Поиск тоже понимает категории и теги.
- Кнопка **«Бриф ⧉»** на карточке копирует в буфер готовый промпт для ИИ-агента:
  «сделай сайт этой категории, но со своим дизайном» + характер референса,
  палитра, шрифты и ссылки. Вставь его в Claude/Cursor и дополни своей задачей.
- Кнопка **«Открыть оригинал ↗»** — переход на исходный сайт в новой вкладке.
- Ссылка **«страница на Refero ↗»** — открывает страницу стиля на refero.design
  (там доп. экраны сайта, палитра, шрифты).

## Цифры

Источник данных: публичный API галереи `styles.refero.design`. Видео и сайты
принадлежат их авторам — копия сделана для личного офлайн-просмотра, все ссылки
ведут на оригиналы.
